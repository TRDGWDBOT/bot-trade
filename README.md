# TRDGWDBOT

Bot di trading automatico per Deriv Multipliers. Backend in Python/FastAPI, frontend in React, database MongoDB.

## 🏗 Architettura

- **Backend** (`/backend`) — FastAPI + Python, connesso via WebSocket all'API Deriv
- **Frontend** (`/frontend`) — React, hostato su GitHub Pages
- **Database** — MongoDB Atlas (cloud)

## 🚀 Deploy

Vedi la guida completa in [`DEPLOY.md`](DEPLOY.md).

## ⚠️ Disclaimer

Il trading comporta rischio di perdita del capitale. Testa a lungo in DEMO prima del reale.
